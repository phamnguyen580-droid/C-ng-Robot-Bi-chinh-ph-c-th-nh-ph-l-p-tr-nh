# Robot Bi Adventure – Tin học 5

Trang web trò chơi học tập Tin học lớp 5 (sách Kết nối tri thức với cuộc sống): 18 bài học, luyện tập, ôn tập, mê cung lập trình cùng Robot Bi, "Hỏi Bi", bảng giáo viên.

## Chạy
- Mở trực tiếp `index.html` bằng trình duyệt, hoặc
- Bật GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Lưu ý
- Một tệp HTML duy nhất, không cần cài đặt hay máy chủ. Chỉ phông chữ Nunito tải từ Google Fonts (mất mạng vẫn chạy, dùng phông thay thế).
- Tiến độ lưu trong `localStorage` của từng trình duyệt (khóa `bi5v2`); không đồng bộ giữa các máy. Giáo viên gom số liệu bằng nút xuất CSV.
- "Hỏi Bi" trả lời theo quy tắc sư phạm có sẵn, không phải AI tạo sinh.
- Mê cung của Bi là cơ chế riêng, không phải khối lệnh Scratch.
- Nội dung Bài 10, 11, 13–16 cần giáo viên đối chiếu thêm với SGK.
